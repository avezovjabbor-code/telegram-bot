# Zamonaviy Kalkulyator Loyihasi

Ushbu papkada to'liq va mustaqil ishlaydigan zamonaviy kalkulyator joylashgan.

## Fayllar tarkibi:
- `index.html` - Kalkulyatorning asosiy HTML sahifasi
- `style.css` - Glassmorphism dizayni, animatsiyalar va Mavzu (Dark/Light) stillari
- `script.js` - Kalkulyator hisoblash mantig'i, xotira (tarix) va klaviatura boshqaruvi

## Qanday ishga tushiriladi?
`index.html` faylini istalgan brauzerda (Google Chrome, Microsoft Edge, Mozilla Firefox) sichqonchaning chap tugmasini 2 marta bosish orqali ochishingiz mumkin. Hech qanday qo'shimcha server yoki dastur o'rnatish talab qilinmaydi.

## Asosiy imkoniyatlari:
1. **Arifmetik amallar**: Qo'shish (+), ayirish (-), ko'paytirish (×), bo'lish (÷), foiz (%).
2. **Klaviatura orqali boshqarish**: Raqamlar, Enter (=), Backspace (o'chirish), Esc (AC).
3. **Mavzuni o'zgartirish**: Qorong'i (Dark) va Yorug' (Light) rejimlar.
4. **Hisoblashlar tarixi**: O'tkazilgan barcha hisob-kitoblar brauzer xotirasida (LocalStorage) saqlanib turadi.
